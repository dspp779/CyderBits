# Cyder 0.13.2

> 正式版本：`0.13.2`（Developer ID + 公證）  
> Engine：`CX26.3.0-W11-Cyder012`（與 0.13.1 相同 pin）

0.13.2 為應用層修正：引擎升級時保留 shared bottle（原地 `wineboot -u`），以及 DXVK 專用的 MoltenVK 偏好 UI。

## 本版修改

### 應用層

- **Bootstrap marker 記引擎版號：** `.cyder-bootstrap-v1` 寫入 `engine=`；與目前引擎不同時對既有 bottle **原地** `wineboot -u`，不再清 marker 後整瓶重建，避免升級誤刪已安裝應用。
- **MoltenVK 偏好：** 僅在圖形轉譯為 DXVK 時顯示；選項只顯示版本號（`1.4.2`／`1.2.10`）。
- **正式產物：** 公證後同時產出 `Cyder.app.zip` 與版本化 `Cyder-<semver>.zip`；release 通道在 staple 後自動跑 graphics／zip 驗收。

### 引擎

本版**不**更換引擎 pin（仍為 `CX26.3.0-W11-Cyder012`）。

## 已知限制

- 需要 Wine Mono／Gecko 的程式第一次載入時，可能出現 Wine 元件安裝提示。
- MoltenVK 1.4.2 僅適用 macOS 12+；更舊系統自動使用 1.2.10。
- 圖形後端（DXVK／DXMT／D3DMetal）仍依遊戲與 macOS 個別驗證。
- Catalina 仍走 Terminal bootstrap／Bash 啟動路徑；macOS 11+ 才有完整原生 UI。

## 正式版建置

