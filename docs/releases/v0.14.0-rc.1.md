# Cyder 0.14.0-rc.1 — 生命週期與介面改善

> Pre-release 草稿，套件已完成 Developer ID 簽章、Apple 公證與票據裝訂，尚未公開發佈。App 內版本為 `0.14.0`；預定 GitHub tag 為 `v0.14.0-rc.1`，標示為 pre-release，不設為 latest。

這次候選版改善啟動要求、遊戲環境恢復、選單與退出行為。引擎及圖形元件沿用 0.13.2 的已發佈封存檔；未納入仍在研究中的 DXMT 效能修改。

## 本版改進

- **退出 Cyder 與停止 Windows 環境分開。** Command-Q 與退出選單關閉 Cyder；停止 Windows 環境使用獨立操作。背景觀察或診斷寫入卡住時，退出仍有期限。
- **啟動要求可持久保存與恢復。** 重複傳送使用同一要求識別碼；重開後待處理要求需由使用者恢復，結果不確定的要求不會自動重播。
- **選單與遊戲庫減少等待。** 選單使用狀態快照；資源讀取、圖示、檔案查詢、設定與診斷寫入移至背景，過期結果不再更新已關閉的介面。
- **環境與視窗辨識更精確。** 依程序出生身分、環境世代與可驗證的視窗資訊恢復狀態；缺少證據時保留未知狀態，避免把同名程序或同一環境直接當成同一款遊戲。
- **協調服務不可用時仍保留介面。** 遊戲庫及唯讀資訊可繼續使用，失敗環境不阻塞其他環境。
- **改善設定視窗與診斷可靠度。** 修正設定視窗初始化、晚到進度更新，並限制診斷佇列、輔助程式輸出及恢復標記大小。

## 驗證範圍與已知限制

- 應用層已完成 A–F 實作，以及正式程式路徑的事件重放、測試替身與故障注入。詳細證據與各項限制見 [生命週期交付報告](../superpowers/reports/2026-09-23-cyder-lifecycle-delivery.md)。
- 打包主機為 macOS 27.0.1（26A434）。目前系統無法執行 x86 程式，因此**本候選包尚未完成真實 Wine／NGS 遊戲相容性驗證**。替代測試通過不代表 Wine 或 NGS 相容性通過。
- 跨 Space、VoiceOver、真實滑鼠操作至選單呈現的延遲，以及最新版完整 Wine 多視窗／背景留存／恢復流程，仍需實機驗收。
- 無法確認程序歸屬或要求執行結果時，介面可能保留未知／待確認狀態；不自動重派不確定的要求。
- 一般診斷日誌滿載時可丟棄並記數；寫入持續受阻時退出優先，最後診斷可能未落盤。
- Apple Silicon 執行 Wine 仍需要可用的 Rosetta。MoltenVK 1.4.2 需 macOS 12+；較舊系統使用 1.2.10。macOS 10.15 使用 Terminal bootstrap／Bash 路徑，完整原生 UI 需 macOS 11+。

## 建議試用重點

1. 啟動遊戲後退出 Cyder，確認遊戲持續執行；重開 Cyder 後確認環境狀態可恢復。
2. 開啟多個遊戲與視窗，確認切換目標正確；明確停止指定環境時，其他環境不受影響。
3. 環境準備期間使用遊戲庫、設定與選單；重開時確認歷史要求沒有自動重播。
