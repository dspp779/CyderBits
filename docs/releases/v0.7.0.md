# Cyder 0.7.0

Cyder 0.7.0 強化 CrossOver bottle 隔離與重建、Winetricks 工具鏈，並更新 App 圖示。正式版仍使用 CX26.3 Cyder004；MapleStory OEM 以獨立 flavor（`0.7.0-maplestory-oem25`）打包，引擎與 bottle 路徑與正式版並存、互不覆蓋。

**引擎標籤（正式版）：** `CX26.3.0-W11-Cyder004`  
**OEM flavor：** MapleStory OEM CrossOver `25.0.1.38865`（`maplestory-oem25` engine / bottle）

## 更新重點

### CrossOver bottle 隔離與重建

- 以 `CYDER_ENGINE_NAME` / `CYDER_BOTTLE_NAME` 區分 runtime 與 bottle；OEM 預設為 `maplestory-oem25`。
- 設定主鍵改為 `CYDER_PREFIX`（保留 `CYDER_SHARED_PREFIX` 別名）。
- CrossOver bottle 會從 engine 的 `cxbottle.conf` 範本 seed；MapleStory OEM 另注入 `RAW_AUDIO_PARSE` 與 `zh_TW.UTF-8` locale。
- Bottle 重建改為先刪除再重建；不完整 OEM bottle（缺 `cxbottle.conf`）不會被當成就緒。

### Winetricks / cabextract

- 內建 universal `cabextract`，配合設定內的原生 Winetricks 安裝流程。

### MapleStory OEM flavor

- `scripts/create-cyder-maplestory-oem-app.sh` 以正式版打包流程為底，替換 OEM 啟動／bootstrap 腳本並重新簽署。
- CrossOver Perl frontend 才會帶入官方 Launcher 風格旗標；正式版 Mach-O wine 不會誤加這些參數。

### 品牌圖示

- 打包改優先使用 `logo/AppIcons.zip`／`AppIcon.appiconset` 產生 `AppIcon.icns`。

## 安裝與升級

1. 下載並解壓對應的 `Cyder-0.7.0.zip`（正式版）或 `Cyder-maplestory-oem25-0.7.0.zip`（OEM）。
2. 以新版 `.app` 取代舊版；正式版與 OEM 可同時安裝，runtime／bottle 名稱不同。
3. 若 OEM bottle 曾因缺 `cxbottle.conf` 失敗，請在設定中重建 bottle。

## 已知限制

- MapleStory OEM 相容性路徑僅存在於 OEM flavor，不併入正式版 0.7.0 一般用途 engine。
- Apple Silicon 仍需 Rosetta 2；Swift 設定／遊戲庫 UI 仍需 macOS 12+。
