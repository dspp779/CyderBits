## 重點

- **修正更新 Windows 環境時可能崩潰的問題。** 針對 macOS 15.8 上的啟動失敗，重建引擎及相關元件，避免使用舊版 macOS 尚未提供的系統功能（[engine #14](https://github.com/dspp779/cyder-wine-engine/pull/14)）。
- **結束遊戲後再次啟動更可靠。** 背景狀態更新短暫占用啟動記錄時，現在會稍候重試，避免立即顯示無法啟動（[修正](https://github.com/dspp779/CyderBits/commit/d1c7cf90766c796ac4671cd15e2d382fe0eb0acc)）。
- **從 Finder 開啟 .exe 時，會看到「正在啟動程式…」進度視窗。** 先前 Cyder 不在前景時，這個視窗被擋在目前程式後方，看起來像卡住；現在會顯示在最上層，但不會搶走焦點。每次啟動的元件完整性檢查也只執行一次（[#24](https://github.com/dspp779/CyderBits/pull/24)）。
- **引擎名稱維持 Cyder013。** App 以封裝內容辨識更新；即使名稱相同，也會安裝修正版。更新 App 後，請依提示更新 Windows 環境。

本版沒有新增經遊戲實測的相容性修正。

## 已知限制

- **本版未經遊戲實測。** 已完成本機引擎啟動、兩種 Windows 架構的檔案與加密操作測試；macOS 15.8 的原始更新案例，以及 macOS 10.15／11，仍待實機驗證。
- 影片解碼與 HTTPS／TLS 端到端流程尚未重新實測。
- 0.14 系列是最後支援 macOS 10.15／11 的版本；不含 DXVK 2。
