## 重點

- **舊版 macOS 更新 Windows 環境時不再當掉**（例如 macOS 15.8）。更新 App 後，請依提示更新 Windows 環境。
- **啟動更快。** 開啟程式約快 1.5 秒；另一個程式還在啟動時，再開一個不必久等。
- **看得到啟動進度。** 從 Finder 開啟 .exe 時，「正在啟動程式…」會顯示在最上層，程式出現或當掉時自動關閉，程式也會移到前景。
- **缺少 Windows 元件時，會說明缺少哪一個檔案。**
- **結束遊戲後可以馬上再開。**
- **重新開機後，狀態不再停在「正在確認執行狀態…」。**
- **程式結束後不再殘留背景程序。**
- **DXVK 圖形元件會隨 App 一起更新。**

## 遊戲修正

本版沒有新增經遊戲實測的相容性修正。

## 已知限制

- **本版未經遊戲實測。** 已完成本機引擎啟動、兩種 Windows 架構的檔案與加密操作測試；macOS 15.8 的原始更新案例，以及 macOS 10.15／11，仍待實機驗證。
- 影片解碼與 HTTPS／TLS 端到端流程尚未重新實測。
- 0.14 系列是最後支援 macOS 10.15／11 的版本；不含 DXVK 2。
