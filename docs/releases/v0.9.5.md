# Cyder 0.9.5

引擎更新為 `CX26.3.0-W11-Cyder009`。高解析度顯示改為預設開啟，並在初始化（golden baseline）時套用。

## 主要變更

- **Cyder009 引擎：** 保留 Cyder008 的 A6／teardown／MoltenVK shim，並加入 `NtQueryDirectoryObject` 的窄範圍 `optnone` bandage，緩解部分遊戲（如楓之谷經典版）離開後 Grap／NGS 目錄物件忙碌迴圈。
- **高解析度顯示預設開啟：** RetinaMode=`y`、DPI=192；新瓶／重建環境的 golden baseline 會寫入相同預設。
- **啟動文案：** 已初始化過的環境改顯示「正在檢查遊戲環境…」，不再一律顯示「正在準備遊戲環境…」（仍會做引擎指紋與 health-check，屬預期行為）。
