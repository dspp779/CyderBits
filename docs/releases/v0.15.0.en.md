> [!IMPORTANT]
> **From 0.15.0 Cyder requires macOS 12 or later.** On macOS 10.15 and 11, keep using [0.14.1](v0.14.1.en.md).
> The first time you open it after updating, update the Windows environment when asked (new engine Cyder014).

## Highlights

- **Cities: Skylines II runs on Apple Silicon.** With its graphics setting left on "default" it uses DXMT; the unmodified game reaches the main menu, starts a new city, saves and loads ([#10](https://github.com/dspp779/CyderBits/issues/10)).
- **Shorter waits when MapleStory first loads a map or skill.** New WZ read-ahead, merged with the WZ cache into one setting, "MapleStory WZ 檔案讀取最佳化", on by default.
- **End a single program from the menu bar or the game library.** Each opened program shows a status such as 執行中 or 在背景執行 and offers 結束…; when it does not respond, 強制結束…. Both ask first.
- **More reliable launch detection:** force-quitting a fullscreen game no longer reports "程式在顯示視窗前就結束了", a fullscreen launch no longer makes the next launch wait 30 seconds, other games still start while an error message is open, and a double-click opens one copy.
- **The Windows environment no longer crashes when a game is force-quit**; Steam and other programs keep running.
- **Older Intel Macs are no longer given DXMT, which cannot run there**; Cyder picks graphics that work or explains why before launch.

## Game fixes

- **Cities: Skylines II:** stopped on a black screen after an `IOException` while listing files. Unity's Mono read the Windows "last error" from the wrong place on macOS; the engine now reads it from the real thread data ([engine #17](https://github.com/dspp779/cyder-wine-engine/pull/17)). With graphics on "default" it uses DXMT, the only backend that draws correctly (D3DMetal leaves the city black, DXVK stops at the main menu). Needs GPU Family Mac 2 (Apple Silicon); older Intel Macs show `CYD-GFX-002` before launch. [Guide (zh-TW)](../games/cities-skylines-2/README.md).
- **Steam games:** opened directly from Cyder under `steamapps/common/`, some games could not initialise Steam without a Steam App ID. Cyder now reads the App ID from Steam's `appmanifest` and passes it to the game.
- **MECCHA CHAMELEON:** black main-menu background on DXVK. With graphics on "default" it uses DXMT with `-dx11`; Macs that cannot run DXMT use D3DMetal, else DXVK.
- **MapleStory:** WZ read-ahead reads the following data of a WZ file ahead of time. Measured once per graphics backend on Apple Silicon, the first-load wait dropped by about 70% (DXVK 388 → 108 ms); no repeated measurements.

## New features and improvements

### Launching and lifecycle

- **Fullscreen windows are recognised.** Wine raises a fullscreen window to a higher window level when the game becomes the active app. Cyder only looked at the normal level, so it saw no window: force-quitting the game reported `CYD-WIN-002`, and a game left running held the next launch for the full 30 seconds.
- **Error messages no longer hold other launches.** While an error dialog was open, new launch requests waited and then all ran at once when it closed, so a few clicks opened several copies of a game.
- **Repeated launch requests run once.** A request for the same program and arguments is skipped while one is queued, being prepared, launching, or started less than 10 seconds ago. Different arguments (a new login, for example) still run.
- **No false error when a launcher exits first.** When a launcher starts the game and exits with an error code before the game's window appears, Cyder keeps waiting while programs of that launch are still running and treats a window as a successful start.

### Program control

- **One menu bar row per opened program**, named after its game library title when there is one; statuses 正在啟動…, 執行中, 在背景執行, 正在結束… and 沒有回應. Wine's own background programs are not shown.
- **結束… (End)** asks the program to close, like its window's close button, so a game can save first. It always asks for confirmation; ending Steam while games run warns that they may stop working or fail to save.
- **強制結束… (Force quit)**: if the program is still running 5 seconds after 結束, its status becomes 沒有回應 and force quit is offered (also confirmed; unsaved progress is lost). It ends only that row's programs, never Wine's background programs.
- **Game library**: for a running game, 啟動遊戲 becomes 顯示 (Show) with 結束… next to it; opening a running game again brings it forward instead of starting a second copy.
- **Result after a program ends**: its row stays for 8 seconds with 已結束 (ended), 意外結束 (quit unexpectedly: Wine's crash dialog appeared) or 已由你結束 (ended by you, through 結束 or 強制結束).
- Ending a program that is still starting no longer shows `CYD-WIN-002` afterwards.

### Graphics

- **The GPU is checked before DXMT is chosen.** DXMT needs Metal GPU Family Mac 2. On older GPUs MapleStory falls back to DXVK, the DXMT setting is disabled with the reason, and games that only work with DXMT stop before launch with `CYD-GFX-002`.
- **Only MoltenVK 1.4.2 is shipped; the MoltenVK version setting is gone.** A setting that pointed at 1.2.10 is changed to 1.4.2.
- When DXMT is unavailable, Settings says whether macOS, the GPU or the graphics package is the reason.

## Known issues

- **Older Intel integrated graphics have not been tested with MoltenVK 1.4.2** ([#7](https://github.com/dspp779/CyderBits/issues/7)). Only 1.2.10 was known to work on these Macs; please report if classic MapleStory draws incorrectly.
- **macOS 26 has not been tested** (the `wineboot` crash in [#23](https://github.com/dspp779/CyderBits/issues/23) is expected to be fixed by Cyder014).
- **Cities: Skylines II:** building and long play sessions, Paradox Mods and settings persistence were not tested; launch without the Paradox Launcher. Intel Macs with GPU Family Mac 1 cannot run it.
- **Not tested on Intel Macs:** force-quitting a real game, fullscreen window recognition, the MECCHA CHAMELEON rule.
- **Launch detection:** windows on another Space or minimised to the Dock are not counted; a launcher exiting first was tested only with a batch file.
- **Program control:** 結束 closes every program with the same name in that Windows environment; games started from inside Steam belong to Steam's row; after reopening Cyder, a game already running shows 顯示 in the library only after its next launch. The menu bar's 結束 and 強制結束 are covered by automated tests; only the library flow (Steam) and a test program that crashes on purpose were tried on a real Mac. 意外結束 is shown only when Wine's crash dialog appears; a program that vanishes without one shows 已結束.
- The MapleStory first-load improvement was measured once per backend on Apple Silicon; no FPS improvement is claimed.
