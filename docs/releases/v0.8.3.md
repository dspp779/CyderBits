# Cyder 0.8.3

Cyder 0.8.3 是僅更新正式版 Wine engine 的相容性修正版。App 功能、使用者介面、共享 bottle 格式與 MapleStory OEM flavor 均未變更。

**正式版引擎：** `CX26.3.0-W11-Cyder006`  
**底層版本：** CrossOver 26.3.0 / Wine 11.0

## 修正

- 在 x86_64 `RtlWalkFrameChain()` 中保護 `RtlVirtualUnwind2()`：遇到無效或執行期間變動的 unwind metadata 所引發的 page fault 時，安全結束目前的 stack walk，不再讓例外逃回應用程式 handler 並遞迴至 stack overflow。
- 修正《新楓之谷：經典版》停在「登入中，請稍候」的問題。

## 驗證

Cyder006 已實測通過 DirectX 11 初始化、登入、選擇伺服器與角色、GRAP 安全模組、進入遊戲地圖，以及由使用者正常結束遊戲。原有 Cyder/CrossOver macOS 修補與 MoltenVK runtime 均保留。
