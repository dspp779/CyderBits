# Cyder 0.10.0

> 目標版本：`0.10.0`（目前以 test channel 驗證）

本版本將 Wine engine 更新為 `CX26.3.0-W11-Cyder010`，重點是圖形轉譯後端、
啟動診斷與選單列多程序體驗的整合。正式發佈前仍需完成實際遊戲回歸測試，尤其是
DXMT 與 Steam／反作弊程序的生命週期。

## 主要變更

- **Cyder010 engine：** 使用 `CX26.3.0-W11-Cyder010` engine artifact，包含
  更新後的 MoltenVK runtime 與 Cyder 圖形相容性修正。
- **DXVK 2：** 暫不隨 0.10.0 出貨。由於目前 MoltenVK 無法安全提供 DXVK 2.7.1
  所需的 Vulkan robustness／null-descriptor 能力，相關 UI、payload 與啟動路徑已移除，
  待後續找到可行 backend 實作再重新評估。
- **DXMT／D3DMetal runtime：** 圖形 payload 由 Cyder ensure 流程準備，DXMT 的
  `winemetal.dll` 會同步覆蓋至 prefix，避免使用舊版本或缺少基礎 DLL；舊的 prefix
  migration 不再刪除該檔案。
- **CompatDB 圖形載入：** 圖形 backend/prepend 由自製 `cxcompatdb.so` 處理，
  不再依賴 Cyder 特有的 ntdll patch；backend 路徑、格式與載入錯誤會被檢查並寫入
  診斷記錄。
- **偏好設定套用時機：** 同步機制、高解析度與字體等需要新 Wine session 的設定，
  在有執行中 session 時會顯示待套用狀態與「套用設定」按鈕；其他設定即時寫入。
- **單一選單列 icon：** 同一 bundle／support root 的 Cyder native instance 會共用
  一個 primary icon；偏好設定與遊戲庫可由選單列直接開啟。
- **Wine session 狀態：** 選單列會顯示啟動中的 Wine session 與根程序結束後的
  背景等待狀態，並維持同一 icon 下的 session 聚合。
- **診斷檔案收斂：** `settings.json` 保存設定狀態與最後修改時間，
  `settings-apply.log` 使用單一 rolling 檔案，遊戲執行則保留最後一次的
  `last-wine-launch` session log。
- **Winetricks 目錄收斂：** Steam、Visual C++ runtime 與 .NET Desktop Runtime
  不再由 Cyder 內建選擇器安裝；使用者可從官方來源下載 Windows installer，再透過
  Cyder 安裝到目前 prefix。保留需要 Wine 專用處理的常見元件，例如 `wmp9`、
  `quartz`、`devenum`、`vb6run`。
- **引擎版本顯示：** 偏好設定「一般」頁將 engine 版本放在頁尾，以較小灰色字體
  顯示版本號，並與「引擎版本」標籤分開對齊。

## 使用者可見的行為變更

- 同一 Cyder 執行環境不會因 Finder／LaunchServices 建立短暫 instance 而出現多個
  選單列 icon。
- 需要重啟 session 的設定不會在執行中的 Wine 程序上假裝立即生效；使用者可以看見
  待套用狀態，並選擇在適當時間套用。
- Steam、Visual C++ runtime、.NET installer 的安裝責任回到使用者，可依遊戲需要
  選擇版本與來源，避免 Cyder 內建 Winetricks catalog 綁定過時套件。

## 已知限制與後續工作

- 目前 session 完成判斷仍以 lifecycle sidecar 與 prefix-level `wineserver -w`
  作為後備；Steam 的 `steam.exe` 提前退出、helper reparent，以及同一 prefix 同時
  執行多個程式時，仍可能出現「等待背景程序」的保守顯示。
- 已新增 [Cyder Session 與 Windows 程序監控設計](../cyder-session-process-monitoring.zh-TW.md)，
  下一階段將以 LaunchGroup 與 Wine 內隱藏 Win32 monitor 分辨根程序、子孫程序與
  前景程序；本 release note 所對應版本尚未宣稱該 monitor 已完成。
- DXMT 與部分反作弊程序仍需在實際遊戲上驗證啟動、離場與背景程序清理。
