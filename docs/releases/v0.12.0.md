# Cyder 0.12.0

> 正式版本：`0.12.0`（Developer ID + 公證）

0.12.0 是 0.11.1 之後的應用層發佈：選單列改以 LaunchGroup 管 Wine 壽命、遊戲庫圖示改走 Wine `winemenubuilder`、並補上語系選單、捷徑名稱與 Dock／Cmd-Tab。Engine 仍為 `CX26.3.0-W11-Cyder011`。CX25 OEM 產品線已退役。

## 本版修改

- **選單列壽命：** 啟動當下建立 LaunchGroup；pid 檔、視窗與 Dock 認領接到同一組。根行程提早結束時仍可認領同 bottle 視窗，不再靠 sentinel helper 斷線當遊戲結束。
- **遊戲庫圖示：** 以暫存 `.lnk` + `winemenubuilder.exe -t` 抽圖，快取 PNG；EXE mtime 變更會重抽。Cyder.app 不再內建 CyderBits Python。
- **捷徑名稱：** 磁貼優先顯示 Start Menu／桌面 `.lnk` 名稱；過長標題兩行換行後再截斷。
- **Windows 語系：** 全域選單為系統、中文、日文、英文；說明目前偵測到的 macOS 語言，並註明 wineserver 仍在跑時代碼頁不會立刻更新。
- **URI 協定：** 開啟偏好設定時背景掃描一次（分頁切換不再重掃）；registry 用 rg／grep 抽取區段。預設 handler 探測改用階層式 URL。
- **Dock：** EXE／URI 啟動仍不佔 Dock；開啟遊戲庫或偏好設定時暫時升成 Dock 應用，方便 Cmd-Tab。點已常駐的 Cyder.app 會重開遊戲庫。
- **其他：** CyderSwift 在 Apple Silicon 以 arm64 執行；安靜模式 `last-wine-launch.log` 上限 16 MiB；退役 CX25 OEM 建置與包裝路徑。

## 正式版建置

```bash
bash scripts/release-cyder.sh --channel release --version 0.12.0
```
