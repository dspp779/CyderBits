# Cyder 0.11.1

> 正式版本：`0.11.1`（Developer ID + 公證）

0.11.1 是 `gamaniagames://` URI 處理與選單列工作的正式發佈。相對先前的 `v0.11.0` tag，本版補上 URI 冷啟動不再開啟偏好設定，以及 URI 協定清單將「啟用」放在第一欄。Engine 仍為 `CX26.3.0-W11-Cyder011`。

## 本版修改

- **gamaniagames://：** 在 shared bottle 偵測 GGM 註冊後，可由 Cyder 接收 URI，並以 `GGMWebStart.exe` 原樣傳入（`absoluteString`，不解碼 `%20`）。
- **URI 協定設定：** 切換到該分頁才掃描；清單欄位為啟用、URI、EXE、命令、版本。勾選會接管 Launch Services，取消則嘗試還原先前 handler。
- **`open -n -b` EXE：** 接受 macOS 以 `file://` 送入的 `.exe`，避免參數進 argv、遊戲檔卻被當成無效文件。
- **URI 冷啟動：** `open 'gamaniagames://…'` 不再同時跑環境／圖形檢查或開啟偏好設定。
- **選單列：** 醒酒瓶 icon 與 Wine session 生命週期顯示（含於本線合併）。

## 正式版建置

```bash
bash scripts/release-cyder.sh --channel release --version 0.11.1
```

預期 engine label：

```text
CX26.3.0-W11-Cyder011
```
