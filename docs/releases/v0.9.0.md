# Cyder 0.9.0

Cyder 0.9.0 將正式 Wine engine 升級至 `CX26.3.0-W11-Cyder007`，並帶來可管理的
Wine 診斷記錄、較清楚的同步設定，以及可驗證的引擎發布流程。

**正式版引擎：** `CX26.3.0-W11-Cyder007`  
**底層版本：** CrossOver 26.3.0 / Wine 11.0

## 引擎與相容性

- `RtlWalkFrameChain()` 現在會在找不到 function entry 時安全停止，並保護
  `RtlVirtualUnwind2()` 對無效或執行期間變動 unwind metadata 的 page fault。
- 修正《新楓之谷：經典版》登入流程可能卡住或遞迴至 Wine stack overflow 的問題。
- 保留既有的 A6 same-view backing sync、x86_64 MoltenVK runtime 與 i386/x86_64 Windows
  PE 支援。

## 診斷與設定

- 新增「安靜／只記錄錯誤／完整堆疊追蹤」Wine 診斷模式；高容量模式會顯示明確警告。
- 啟動記錄以 gzip 壓縮，可匯出最近一次遊戲記錄或清除除錯記錄。
- 診斷記錄會包含 engine version、NTDLL SHA-256、圖形後端與同步設定；遊戲命令列參數
  不會寫入永久記錄。
- MSync／ESync 改為單一同步機制選擇器，支援全域與個別遊戲設定。

## 發布完整性

- 引擎 archive 會以 manifest、archive SHA-256、內嵌 manifest 與 NTDLL SHA-256 驗證後
  才能被 Cyder 匯入。
- 封裝流程會在 archive 解壓後驗證全部 Mach-O 簽章；Rosetta 安裝改由 macOS 原生流程
  呈現授權與安裝提示。

## 升級注意事項

引擎版本變更時，Cyder 會重建 shared Wine bottle，以避免舊 engine 的狀態影響新 runtime。
遊戲檔案不會刪除，但已安裝的 Windows 元件與自訂設定可能需要重新套用。
