# Cyder 0.9.1

引擎仍為 `CX26.3.0-W11-Cyder007`。本版為 App 側修正與預設調整。

## 變更

- **DXVK + MoltenVK Ports 洩漏：** runtime 套用打包內的 timeline-wait poll shim，避免《新楓之谷：經典版》長跑時 Mach Ports 暴增（minOS 10.15）。開啟 Cyder.app 或啟動遊戲時會冪等套用（含自 0.9.0 升級、引擎版號未變）；使用者端不會現場編譯。
- **經典版預設 DXVK：** 全域圖形為「預設」時，CompatDB 對 `Maplestory_Classic.exe` 自動選 DXVK；明確選 D3DMetal／DXVK／WineD3D（或「自動」）仍以全域為準。

## 引擎

`CX26.3.0-W11-Cyder007`（與 0.9.0 相同；MoltenVK 修復並完成驗證後，才可移除此 shim overlay）
