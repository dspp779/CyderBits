# Cyder 0.9.1

Cyder 0.9.1 在**不變更**引擎標籤 `CX26.3.0-W11-Cyder007` 的前提下，於 runtime
注入 MoltenVK **timeline-wait poll** shim，避開《新楓之谷：經典版》+ DXVK 長跑時的
Mach Ports 洩漏。

## 重點

- App ensure engine 後冪等套用 wait-poll shim（`libMoltenVK.dylib` → shim，
  `.real` 保留原廠 MoltenVK）。
- App Resources 內建預編 x86_64 shim；消費者機不需 clang。
- 引擎 archive／版號字串不變；正式重編 MoltenVK 進下一顆引擎後應移除此 overlay。

詳見：

- [`docs/maplestory-classic-dxvk-ports-leak.md`](../maplestory-classic-dxvk-ports-leak.md)
- `cyder-wine-engine/docs/moltenvk-timeline-wait-poll-app-overlay.md`

## 驗收建議

- Classic + DXVK 長跑：Activity Monitor 中 wine 行程 **Ports 不再持續爬升**。
- D3DMetal／WineD3D 仍可啟動。
- `strings …/libMoltenVK.dylib` 可見 `cyder-moltenvk-timeline-wait-poll`。
