# Cyder 0.8.0

Cyder 0.8.0 新增圖形轉譯後端偏好（WineD3D / DXVK / D3DMetal），兩套引擎（正式 CX26 與 MapleStory OEM）皆內建共用 DXVK payload。正式版 engine 升級至 **CX26.3.0-W11-Cyder005**（含 DXVK 與 graphics runtime）；MapleStory OEM 以獨立 flavor（`0.8.0-maplestory-oem25`）打包，引擎與 bottle 路徑與正式版並存、互不覆蓋。

**引擎標籤（正式版）：** `CX26.3.0-W11-Cyder005`  
**OEM flavor：** MapleStory OEM CrossOver `25.0.1.38865`（`maplestory-oem25` engine / bottle）

## 更新重點

### 圖形後端偏好

- 全域與每遊戲設定可選 `default` / `wined3d` / `dxvk` / `d3dmetal`。
- `default` 不覆寫 CompatDB；其餘選項在啟動時強制套用。
- 選 DXVK 時可設定限幀 **60（預設）** 或 **不限制**（見下方說明）。
- D3DMetal 需 **macOS 14+** 且本機有可用的 GPTK（CrossOver 或從評估 DMG 安裝）。

### DXVK

- 正式版與 OEM 引擎皆內建相同 `lib/dxvk` artifact（D3D11/DXGI + MoltenVK）。
- Bottle bootstrap 繼續透過 `install-dxvk-prefix.sh` 將 DXVK PE 裝入 prefix。

### GPTK / D3DMetal

- **Cyder 不出貨、不內建 Apple GPTK**；公證包與 engine tarball 皆不含 `apple_gptk`。
- 若已安裝 CrossOver，可直接使用其 `lib64/apple_gptk`。
- 否則可在偏好設定中從 Apple「Evaluation environment for Windows games」DMG 安裝至 Cyder runtime（需先掛載並同意授權）。

### 設定 schema

- `settings.json` 升級至 schema 4，新增 `graphicsBackend` 與 `dxvkFrameRate` 欄位。

## 安裝與升級

1. 下載並解壓對應的 `Cyder-0.8.0.zip`（正式版）或 `Cyder-maplestory-oem25-0.8.0.zip`（OEM）。
2. 以新版 `.app` 取代舊版；正式版與 OEM 可同時安裝，runtime／bottle 名稱不同。
3. 若需 D3DMetal，請確認 macOS ≥ 14 並準備 CrossOver 或評估 DMG 來源 GPTK。

## 已知限制

- GPTK 不可再散布；僅能使用本機 CrossOver 或使用者自行從官方評估 DMG 安裝的副本。
- D3DMetal 選項在 macOS 13 及以下會灰掉。
- DXVK 限幀（`DXVK_FRAME_RATE=60`）與遊戲內 VSync 為不同機制；若遊戲強制 VSync，實際幀率可能仍受遊戲限制。
- 本版不啟用 MetalFX；UI 不暴露 `dxmt` 選項。
- Apple Silicon 仍需 Rosetta 2；Swift 設定／遊戲庫 UI 仍需 macOS 12+。
