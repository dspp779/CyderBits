# Cyder 0.8.0

> CX25 OEM 產品線與 `--cx 25` 建置已退役。現行路徑是正式 Cyder.app + CX26。本文保留為研究紀錄。

Cyder 0.8.0 以圖形轉譯為主軸更新：正式版與 MapleStory OEM 都加入可切換的 Direct3D 後端、共用的 DXVK payload，以及可在偏好設定中管理的 GPTK / D3DMetal 流程。正式版引擎升級至 **CX26.3.0-W11-Cyder005**；OEM 仍以獨立 flavor（`0.8.0-maplestory-oem25`）出貨，與正式版的 runtime、engine、bottle 路徑完全隔離。

**引擎標籤（正式版）：** `CX26.3.0-W11-Cyder005`  
**OEM flavor：** MapleStory OEM CrossOver `25.0.1.38865`（`maplestory-oem25` engine / bottle）

## 更新重點

### 圖形後端偏好

- 新增全域與每遊戲圖形設定，可在 **預設 / 自動 / D3DMetal / DXVK / WineD3D** 之間切換。
- 正式版的 **預設** 會跟隨 CompatDB；**自動** 會依本機能力依序選擇 **D3DMetal → DXVK → WineD3D**。
- MapleStory OEM 預設走 **自動** 路徑，因此不會與正式版的 CompatDB 圖形規則互相干擾。
- 選 DXVK 時可設定限幀 **60（預設）** 或 **不限制**。
- 圖形設定可在 Cyder 偏好設定與個別遊戲設定中分別調整。

### DXVK 與引擎

- 正式版與 OEM 引擎都內建同一套 DXVK payload。
- 0.8.0 的 DXVK 內容包含 `d3d9`、`d3d10`、`d3d10_1`、`d3d10core`、`d3d11`、`dxgi`，由引擎 bootstrap 自動配置到 Wine prefix。
- DXVK 與 MoltenVK 現在屬於正式出貨 payload，不需要再額外手動補檔。

### GPTK / D3DMetal

- **Cyder 不出貨、不內建 Apple GPTK**；公證包與 engine tarball 都不含 `apple_gptk`。
- 若本機已安裝 CrossOver，Cyder 會優先直接使用 CrossOver 內的 GPTK。
- 若沒有 CrossOver，可在偏好設定中從 Apple「Evaluation environment for Windows games」DMG 安裝 GPTK 到 Cyder runtime。
- D3DMetal 需 **macOS 14+**；在較舊系統上會自動停用。

### MapleStory OEM flavor

- OEM 版沿用獨立 bundle identifier 與獨立 Application Support 路徑，可與正式版並存。
- 舊版 MapleStory OEM bottle 會自動遷移到新路徑，避免覆蓋正式版資料。
- OEM 版同樣具備 DXVK / D3DMetal / WineD3D 切換能力，但維持自己的 engine 與 bottle 空間。

### 相容性資料庫與工具鏈

- App 內附預編譯 CompatDB，安裝與啟動不再依賴打包時的 PyYAML。
- 設定檔升級至 schema 5，包含圖形後端、DXVK 限幀與 HUD 相關欄位。

## 安裝與升級

1. 下載並解壓 `Cyder-0.8.0.zip`（正式版）或 `Cyder-maplestory-oem25-0.8.0.zip`（OEM）。
2. 以新版 `.app` 取代舊版；正式版與 OEM 可同時安裝。
3. 首次啟動後，Cyder 會重新檢查 shared engine 狀態；若你先前使用舊版測試包，建議讓新版 app 重新安裝 engine。
4. 若要使用 D3DMetal，請確認 macOS ≥ 14，並準備 CrossOver 或 Apple 評估 DMG 來源的 GPTK。

## 已知限制

- GPTK 不可再散布；僅支援本機 CrossOver 或使用者自行從官方評估 DMG 安裝的副本。
- D3DMetal 在 macOS 13 及以下會灰掉。
- DXVK 限幀（`DXVK_FRAME_RATE=60`）與遊戲內 VSync 為不同機制；若遊戲強制 VSync，實際幀率可能仍受遊戲限制。
- 本版不啟用 MetalFX；UI 也不暴露 `dxmt` 選項。
- Apple Silicon 仍需 Rosetta 2；Swift 設定／遊戲庫 UI 仍需 macOS 12+。
