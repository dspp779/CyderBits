# Cyder 0.8.3

Cyder 0.8.3 is a compatibility release that updates only the official Wine engine. App features, user interface, shared-bottle format, and the MapleStory OEM flavor are unchanged.

**Official engine:** `CX26.3.0-W11-Cyder006`  
**Base version:** CrossOver 26.3.0 / Wine 11.0

## Fixes

- Guard `RtlVirtualUnwind2()` inside x86_64 `RtlWalkFrameChain()`. A page fault caused by invalid or runtime-modified unwind metadata now terminates the current stack walk instead of escaping to the application handler and recursively ending in a stack overflow.
- Fix MapleStory Classic remaining at its “logging in, please wait” screen.

## Validation

Cyder006 was tested through DirectX 11 initialization, login, server and character selection, the GRAP security module, entering the game world, and a clean user-requested exit. Existing Cyder/CrossOver macOS patches and the MoltenVK runtime remain included.
