# Cyder 0.13.1

> 正式版本：`0.13.1`（Developer ID + 公證）  
> Engine：`CX26.3.0-W11-Cyder012`（Developer ID 簽署；含 dual MoltenVK + GameSir 平台 patch）

0.13.1 升級至 Cyder012 引擎，補上雙版本 MoltenVK 切換與 Apple Silicon Rosetta 知情同意安裝，並修正引擎版本標籤顯示／ensure。

## 本版修改

### 引擎 Cyder012

- **Dual-variant MoltenVK：** 同時內建 `libMoltenVK-1.4.2.dylib`（minos 12.0）與 `libMoltenVK-1.2.10.dylib`（minos ≤ 10.15）；`libMoltenVK.dylib` 為 wait-poll shim，`.real` symlink 選版。
- **全域偏好：** 偏好設定 → 圖形 → MoltenVK（`1.4.2` \| `1.2.10`）。macOS &lt; 12 強制 1.2.10。舊 Intel 顯示異常（世界層全黑）可改用 1.2.10。
- **GameSir → CX26 平台 patch：** wineserver 時區 bias、registry fsync、winemac 隱藏僅 IME 的 KLID、kernelbase 磁碟空間回退。
- **簽章：** 引擎與 MoltenVK shim／兩顆 real 皆以 Developer ID + runtime + timestamp 簽署，避免使用者端 Gatekeeper／AMFI 擋下解壓後的 Mach-O。

### 應用層

- **Rosetta 知情同意：** Apple Silicon 在 engine ensure 前以 Swift 偵測；缺則顯示同意對話框，同意後才執行 `softwareupdate --install-rosetta --agree-to-license`。取消／失敗回報 `CYD-ROS-001`。
- **引擎版本標籤：** 偏好設定顯示含點號標籤（`CX26.3.0-…`）；信任 tarball 內 `engine-version.txt`，減少誤判重裝。

## 已知限制

- 需要 Wine Mono／Gecko 的程式第一次載入時，可能出現 Wine 元件安裝提示。
- MoltenVK 1.4.2 僅適用 macOS 12+；更舊系統自動使用 1.2.10。
- 圖形後端（DXVK／DXMT／D3DMetal）仍依遊戲與 macOS 個別驗證。
- Catalina 仍走 Terminal bootstrap／Bash 啟動路徑；macOS 11+ 才有完整原生 UI。
