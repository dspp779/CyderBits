# Cyder 0.8.0

Cyder 0.8.0 adds graphics backend preferences (WineD3D / DXVK / D3DMetal). Both engines (official CX26 and MapleStory OEM) ship a shared DXVK payload. The official engine is bumped to **CX26.3.0-W11-Cyder005** (DXVK + graphics runtime). MapleStory OEM ships as a separate flavor (`0.8.0-maplestory-oem25`) with isolated engine and bottle paths so it can coexist with the official app.

**Official engine label:** `CX26.3.0-W11-Cyder005`  
**OEM flavor:** MapleStory OEM CrossOver `25.0.1.38865` (`maplestory-oem25` engine / bottle)

## Highlights

### Graphics backend preferences

- Global and per-game settings support `default` / `wined3d` / `dxvk` / `d3dmetal`.
- `default` does not override CompatDB; any other choice is force-applied at launch.
- When DXVK is selected, frame rate can be capped at **60 (default)** or set to **unlimited** (see below).
- D3DMetal requires **macOS 14+** and a valid local GPTK (CrossOver or Evaluation DMG install).

### DXVK

- Official and OEM engines bundle the same `lib/dxvk` artifact (D3D11/DXGI + MoltenVK).
- Bottle bootstrap still provisions DXVK PE DLLs via `install-dxvk-prefix.sh`.

### GPTK / D3DMetal

- **Cyder does not ship or bundle Apple GPTK**; notarized builds and engine tarballs exclude `apple_gptk`.
- If CrossOver is installed, its `lib64/apple_gptk` can be used directly.
- Otherwise, install from Apple’s “Evaluation environment for Windows games” DMG into the Cyder runtime from Preferences (mount the DMG and accept the license first).

### Settings schema

- `settings.json` upgrades to schema 4 with `graphicsBackend` and `dxvkFrameRate` fields.

## Install / upgrade

1. Download and unzip `Cyder-0.8.0.zip` (official) or `Cyder-maplestory-oem25-0.8.0.zip` (OEM).
2. Replace the previous `.app`; official and OEM can coexist because engine/bottle names differ.
3. For D3DMetal, ensure macOS ≥ 14 and a CrossOver or Evaluation-DMG GPTK source is available.

## Known limitations

- GPTK is not redistributable; only local CrossOver or a user-installed copy from the official Evaluation DMG is supported.
- D3DMetal is greyed out on macOS 13 and earlier.
- DXVK frame limiting (`DXVK_FRAME_RATE=60`) is separate from in-game VSync; games that force VSync may still cap the observed frame rate.
- MetalFX is not enabled in this release; `dxmt` is not exposed in the UI.
- Apple Silicon still needs Rosetta 2; Swift settings / library UI still require macOS 12+.
