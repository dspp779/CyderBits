# Cyder 0.8.0

> CX25 OEM 產品線與 `--cx 25` 建置已退役。現行路徑是正式 Cyder.app + CX26。本文保留為研究紀錄。

Cyder 0.8.0 is a graphics-focused release. Both the official CX26 build and the MapleStory OEM flavor now ship switchable Direct3D backends, a shared DXVK payload, and a Preferences-managed GPTK / D3DMetal flow. The official engine is bumped to **CX26.3.0-W11-Cyder005**. MapleStory OEM continues to ship as an isolated flavor (`0.8.0-maplestory-oem25`) with separate runtime, engine, and bottle paths.

**Official engine label:** `CX26.3.0-W11-Cyder005`  
**OEM flavor:** MapleStory OEM CrossOver `25.0.1.38865` (`maplestory-oem25` engine / bottle)

## Highlights

### Graphics backend preferences

- New global and per-game graphics settings let you choose between **default / auto / D3DMetal / DXVK / WineD3D**.
- In the official build, **default** follows CompatDB while **auto** prefers **D3DMetal → DXVK → WineD3D** based on local capabilities.
- MapleStory OEM defaults to the app-side **auto** path, so it does not depend on the official build's CompatDB graphics rules.
- When DXVK is selected, frame rate can be capped at **60 (default)** or set to **unlimited**.
- Graphics settings are available both in Cyder Preferences and in per-game settings.

### DXVK and engine payloads

- Both official and OEM engines bundle the same DXVK payload.
- The 0.8.0 DXVK set includes `d3d9`, `d3d10`, `d3d10_1`, `d3d10core`, `d3d11`, and `dxgi`, provisioned into Wine prefixes during bootstrap.
- DXVK and MoltenVK are now part of the shipped engine payload, so no extra manual patching is required for supported builds.

### GPTK / D3DMetal

- **Cyder does not ship or redistribute Apple GPTK**; notarized apps and engine tarballs exclude `apple_gptk`.
- If CrossOver is installed, Cyder now prefers CrossOver's GPTK automatically.
- Otherwise, GPTK can be installed from Apple's "Evaluation environment for Windows games" DMG into the Cyder runtime from Preferences.
- D3DMetal requires **macOS 14+** and is automatically disabled on older systems.

### MapleStory OEM flavor

- The OEM build keeps its own bundle identifier and Application Support path, so it can coexist with the official Cyder app.
- Legacy MapleStory OEM bottles are migrated into the new isolated layout instead of overwriting official data.
- OEM also gets DXVK / D3DMetal / WineD3D switching while keeping its own engine and bottle space.

### CompatDB and tooling

- Cyder now ships a precompiled CompatDB, so app packaging and installation no longer depend on PyYAML at release time.
- `settings.json` is upgraded to schema 5, covering graphics backend, DXVK frame limit, and HUD-related fields.

## Install / upgrade

1. Download and unzip `Cyder-0.8.0.zip` (official) or `Cyder-maplestory-oem25-0.8.0.zip` (OEM).
2. Replace the previous `.app`; official and OEM can coexist on the same machine.
3. On first launch, Cyder will re-check the shared engine state; if you previously tested older preview builds, let the new app reinstall its engine payload.
4. For D3DMetal, ensure macOS ≥ 14 and a valid GPTK source from CrossOver or Apple's Evaluation DMG.

## Known limitations

- GPTK is not redistributable; only local CrossOver or a user-installed copy from the official Evaluation DMG is supported.
- D3DMetal is greyed out on macOS 13 and earlier.
- DXVK frame limiting (`DXVK_FRAME_RATE=60`) is separate from in-game VSync; games that force VSync may still cap the observed frame rate.
- MetalFX is not enabled in this release, and `dxmt` is not exposed in the UI.
- Apple Silicon still needs Rosetta 2; the Swift settings / library UI still requires macOS 12+.
