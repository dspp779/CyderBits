# Cyder 0.9.0

Cyder 0.9.0 upgrades the official Wine engine to `CX26.3.0-W11-Cyder007` and
adds manageable Wine diagnostics, clearer synchronization controls, and a
verifiable engine-release workflow.

**Official engine:** `CX26.3.0-W11-Cyder007`  
**Base version:** CrossOver 26.3.0 / Wine 11.0

## Engine and compatibility

- `RtlWalkFrameChain()` now stops safely when no function entry is found and
  protects `RtlVirtualUnwind2()` from page faults caused by invalid or
  runtime-modified unwind metadata.
- Fixes MapleStory Classic login hangs and recursive Wine stack-overflow
  failures.
- Retains the A6 same-view backing sync, the x86_64 MoltenVK runtime, and
  i386/x86_64 Windows PE support.

## Diagnostics and settings

- Adds quiet, errors-only, and full unwind-trace Wine diagnostics, with clear
  warnings for high-volume logging modes.
- Launch logs are gzip-compressed and can be exported for the latest game
  session or cleaned up from Settings.
- Diagnostics include the engine version, NTDLL SHA-256, graphics backend, and
  synchronization settings; game command-line arguments are not persisted.
- Replaces separate MSync and ESync switches with one synchronization selector
  for both global and per-game settings.

## Release integrity

- Cyder imports an engine only after validating its manifest, archive SHA-256,
  embedded manifest, and NTDLL SHA-256.
- Packaging verifies every Mach-O signature after archive extraction, while
  Rosetta installation now uses the native macOS license and installer flow.

## Upgrade note

When the engine version changes, Cyder rebuilds the shared Wine bottle to avoid
carrying runtime state across engines. Game files are not removed, but installed
Windows components and custom settings may need to be reapplied.
