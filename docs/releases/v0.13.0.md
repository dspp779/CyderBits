# Cyder 0.13.0

> 正式版本：`0.13.0`（Developer ID + 公證）  
> Engine：`CX26.3.0-W11-Cyder011`（與 0.12.0 相同 label；應用層發佈）

0.13.0 聚焦首次開機速度、入口 UX，以及打包管線。Shared bottle bootstrap 不再預裝 Wine Mono／Gecko；需要時由 Wine 提示或手動腳本安裝。

## 本版修改

### Bootstrap／首次開機

- **wineboot lifecycle：** 空 bottle 用 `wineboot -i`，既有 `system.reg` 用 `-u`；engine 升級保留 shared，只清 `.cyder-bootstrap-v1`；偏好設定「重建」刪 bottle 後再走 `-i`。
- **不再預裝 Mono／Gecko：** 初始化只做 wineboot、tar、顯示 baseline 與 golden baseline；`.NET`／內嵌網頁改由 Wine on-demand 對話框或 `install-wine-mono.sh`／`install-wine-gecko.sh`。
- **平行與量測：** graphics payload 與 wineboot overlap；`bootstrap-timing.jsonl` 與 first-open Preferences dry-run 量測腳本。
- **MSI 快取：** 全域 downloads 目錄 + per-file download lock（手動／進階安裝腳本仍使用）。

### 應用入口

- 單獨開啟 `Cyder.app`（無文件／URI）一律進**偏好設定**；遊戲庫改由選單開啟。
- Launch intent 改為事件驅動（不再靠固定延遲區分 app-only vs 文件啟動）。
- 支援直接開啟 Windows **`.msi`**（`msiexec /i`；prefix 忙碌時拒絕）。
- 支援直接開啟 **`.bat` / `.cmd`**（`cmd /c`，cwd = 腳本目錄）、**`.lnk`**（`start /wait /unix`）、**`.reg`**（`regedit /s`；prefix 忙碌時拒絕）。
- 遊戲庫右鍵「加入／更新 macOS 應用程式」→ `~/Applications/Cyder/` 精簡捷徑；缺檔案、`open` 失敗會跳出提示（LSUIElement 不再無聲結束）。
- 雙實例轉交失敗／逾時、Catalina bootstrap／shell 啟動失敗，以及缺 Resources 的 UI 入口，改為可見警告。

### 圖形／打包

- 圖形後端依 OS 與 payload 可用性閘門；ensure 依 bundled version 跳過。
- Engine archive 預設 zstd `-22 --ultra`；packed 簽章驗證後可跳過 resign；釘選 CX26.3 zstd artifact。
- Engine 版本字串以含點號標籤為準（`CX26.3.0-…`）；檔名 slug 與 ensure 對齊，避免誤判需重裝／多餘 health-check。

### 設定

- Winetricks 原生選擇器拿掉 .NET Framework（與「不預裝 Mono」政策一致）。
- **高解析度預設關閉**（Retina off／96 DPI），降低相容性問題；需要時可在偏好設定或遊戲選項開啟。
- 偏好設定與遊戲庫支援 `⌘W` 關閉視窗、`⌘Q` 結束 Cyder。

## 已知限制

- 需要 Wine Mono／Gecko 的程式第一次載入時，可能出現 Wine 元件安裝提示；完整 .NET Framework／Desktop Runtime 請用官方 Windows installer 經 Cyder 開啟。
- macOS 遊戲捷徑寫死 EXE／Cyder 絕對路徑；重建 bottle 或搬移 App 後需在遊戲庫「更新 macOS 應用程式」。
- Catalina 仍走 Terminal bootstrap／Bash 啟動路徑；macOS 11+ 才有完整原生 UI。
- 圖形後端（DXVK／DXMT／D3DMetal）仍依遊戲與 macOS 個別驗證。
