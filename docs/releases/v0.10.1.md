# Cyder 0.10.1

> 測試版本：`0.10.1`（目前以 test channel 提供驗證）

0.10.1 是 0.10.0 發布後的修正版，重點是 menu bar icon 行為、WZ 小讀取最佳化、release tooling、測試契約與目前版本文件同步。Engine 更新為 `CX26.3.0-W11-Cyder011`，並內嵌 full-video GStreamer media stack。

## 本版修改

- **強制結束動畫：** 使用者確認「結束所有 Cyder 程序」後，醒酒瓶液面會逐步降低；Reduce Motion 開啟時使用固定低液面。
- **純醒酒瓶 icon：** 移除已不再使用的窗格狀態參數，menu bar icon 只保留醒酒瓶輪廓與生命週期液面／警告狀態。
- **遊戲庫測試：** 補上 bottle shortcut scanner 的 Swift 編譯依賴，讓遊戲庫 harness 能實際編譯與執行。
- **Release dry-run：** release channel dry-run 不再要求實際 App、Developer ID keychain、公證或網路操作；仍會驗證穩定版號並輸出完整建置命令。
- **Cyder011 engine manifest：** artifact 必須包含 `libMoltenVK.dylib`，且不得包含舊的 `libMoltenVK.real.dylib` shim；full-video GStreamer plugins 與 scanner 已內嵌。
- **MapleStory WZ adaptive cache：** 只對唯讀 `.wz` 的小讀取啟用 adaptive read-ahead，production cache table 為 512 slots；Cyder 預設開啟，偏好設定「進階」可關閉。低干擾 I/O 統計、timeline、mmap 與 prewarm 僅保留給開發除錯，不包含在 release engine。
- **MapleStory graphics policy：** `MapleStory.exe` 與 `Maplestory_Classic.exe` 在 macOS 15+ 預設使用 DXMT，舊版 macOS 預設使用 DXVK；明確手動選擇仍優先，payload 不可用時安全回退。
- **Wine 啟動生命週期：** launcher／短生命週期工具在 activation 前以 `status=0` 正常結束時不再誤報 `wine-spawn error`；同一 prefix 的後續 Wine activation 呼叫會由背景中的 Cyder 轉送到前景。
- **版本與文件：** App 建置與 release wrapper 由 `config/cyder-app-version.txt` 統一讀取 `0.10.1`，README、release pipeline 與文件索引同步更新。

## 明確不納入本版

LaunchGroup／Wine hidden Win32 process monitor 不納入 0.10.1，預計排入 0.11.0。0.10.1 仍使用 lifecycle sidecar 與 prefix-level `wineserver -w` 後備，因此 Steam helper reparent、同一 prefix 多遊戲與部分背景程序歸屬仍可能顯示為保守的背景等待。

相關設計仍記錄於[程序監控設計文件](../cyder-session-process-monitoring.zh-TW.md)，但不代表 monitor 已完成。

