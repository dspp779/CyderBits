|---|---|
| Prepared | 2026-11-15 (Draft) |
| Engine | `CX26.3.0-W11-Cyder013`, rebuilt with compatibility fixes (CrossOver 26.3.0 FOSS, Wine 11.0) |
| Supported systems | macOS 10.15+; Game Library and Settings require macOS 11+; Apple Silicon requires Rosetta 2 |

## Highlights

- **Updating the Windows environment no longer crashes on older macOS** (such as macOS 15.8). After updating the app, follow the prompt to update the Windows environment.
- **Faster launches.** Programs open about 1.5 seconds sooner, and opening a second program while another is starting no longer means a long wait.
- **Launch progress you can see.** When you open an .exe from Finder, "正在啟動程式…" stays on top, closes when the program appears or crashes, and the program comes to the front.
- **A missing Windows component is named** in the error.
- **Games can be reopened right after they exit.**
- **After a restart, the status no longer stays at "正在確認執行狀態…".**
- **No background processes are left after a program exits.**
- **DXVK graphics files update with the app.**

## Game fixes

No new game compatibility fixes have been verified through game testing in this release.

## Engine changes

| Change | Origin |
|---|---|
| Wine and GLib avoid system functions newer than macOS 10.15; libidn2 uses its bundled replacement; older systems skip unnecessary packet capture initialization | Cyder ([engine #14](https://github.com/dspp779/cyder-wine-engine/pull/14)) |
| A packaging gate rejects unreviewed weak imports that can crash despite a valid minimum OS marker | Cyder (engine #14) |
| MoltenVK 1.2.10 retains the macOS 10.15 build shipped in 0.14.0 | Cyder; existing OS support retained |

## Known issues

- **Not game-tested.** Local engine startup, file operations and cryptographic checks passed for both Windows architectures. The original macOS 15.8 update case and macOS 10.15/11 still require hardware testing.
- Actual video decoding and end-to-end HTTPS/TLS have not been retested.
- The 0.14 line is the last to support macOS 10.15/11. DXVK 2 is not included.
