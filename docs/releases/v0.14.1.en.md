## Highlights

- **Fixes a possible crash while updating the Windows environment.** The engine and its dependencies were rebuilt to avoid system functions unavailable on older macOS versions, addressing the macOS 15.8 startup failure ([engine #14](https://github.com/dspp779/cyder-wine-engine/pull/14)).
- **More reliable relaunches after a game exits.** Cyder briefly waits for a busy launch record instead of failing immediately when a background status update holds it ([fix](https://github.com/dspp779/CyderBits/commit/d1c7cf90766c796ac4671cd15e2d382fe0eb0acc)).
- **The engine stays Cyder013.** Cyder detects rebuilt engine archives by their contents even when the display version is unchanged. Follow the environment update prompt after updating the app.

## Game fixes

No new game compatibility fixes have been verified through game testing in this release.

## Engine changes

| Change | Origin |
|---|---|
| Wine and GLib avoid system functions newer than macOS 10.15; libidn2 uses its bundled replacement; older systems skip unnecessary packet capture initialization | Cyder ([engine #14](https://github.com/dspp779/cyder-wine-engine/pull/14)) |
| A packaging gate rejects unreviewed weak imports that can crash despite a valid minimum OS marker | Cyder (engine #14) |
| MoltenVK 1.2.10 retains the macOS 10.15 build shipped in 0.14.0 | Cyder; existing OS support retained |

## Known issues

- **Not game-tested.** Local engine startup, file operations and cryptographic checks passed for both Windows architectures. The original macOS 15.8 update case and macOS 10.15/11 still require hardware testing.
- Actual video decoding and end-to-end HTTPS/TLS have not been retested.
- The 0.14 line is the last to support macOS 10.15/11. DXVK 2 is not included.
