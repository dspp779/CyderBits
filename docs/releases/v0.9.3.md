# Cyder 0.9.3

Cyder 0.9.3 將 EXE 的 Wine 啟動環境統一交給 Bash，並把原生偏好設定與遊戲庫 UI 的最低版本降至 macOS 11。Wine engine 更新為 `CX26.3.0-W11-Cyder008`。

## 主要變更

- **macOS 11 UI：** Universal `CyderSwift` 同時支援 Intel 與 Apple Silicon，最低版本為 macOS 11。
- **Catalina 首次安裝：** macOS 10.15 使用可見的 Terminal 顯示初始化階段；完成後會繼續原本的 EXE 啟動請求。
- **單一 Wine 啟動後端：** Finder、遊戲庫與測試啟動都由 Bash 組裝 prefix、CompatDB、GPTK／D3DMetal、圖形、同步、診斷與 Wine 環境。
- **啟動錯誤回報：** App 內啟動使用每次啟動專屬的 PID 與 exit-status sidecar，不解析共用 log 來判斷失敗。
- **受保護資料夾：** 遊戲在 Documents、Desktop、Downloads、雲端、外接或網路磁碟發生相符的早期載入失敗時，Cyder 會建議移至 `~/Games`。權限說明只在實際存取相關位置時由 macOS 按需顯示。
- **除錯設定：** 安靜模式不開啟 Wine trace；錯誤、等待／凍結、完整堆疊追蹤使用各自限定的 `WINEDEBUG` profile。
- **MoltenVK shim：** wait-poll shim 仍為必要的預先打包 overlay，不在使用者電腦現場編譯。
- **引擎防護：** Cyder008 補齊 NTDLL frame-walk guard，並加入 async、pipe 與 completion teardown 防護；封包已通過引擎測試、macOS 10.15 minOS、簽章與 archive round-trip 驗證。

## 發佈安全

- 正式通道只接受穩定 semver。
- 正式包必須包含 x86_64 + arm64 的 native `CyderSwift`；Swift 編譯失敗不再靜默降級。
- 每遊戲自訂環境不能覆寫 prefix、PID/result sidecar、診斷、dynamic loader 或其他 launcher 內部控制值。
