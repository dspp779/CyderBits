# Cyder 0.7.0

Cyder 0.7.0 hardens CrossOver bottle isolation and rebuilds, completes the Winetricks tool chain, and ships a new app icon. The official build still uses CX26.3 Cyder004. MapleStory OEM ships as a separate flavor (`0.7.0-maplestory-oem25`) with isolated engine and bottle paths so it can coexist with the official app.

**Official engine label:** `CX26.3.0-W11-Cyder004`  
**OEM flavor:** MapleStory OEM CrossOver `25.0.1.38865` (`maplestory-oem25` engine / bottle)

## Highlights

### CrossOver bottle isolation and rebuild

- `CYDER_ENGINE_NAME` / `CYDER_BOTTLE_NAME` select runtime and bottle directories; OEM defaults to `maplestory-oem25`.
- Prefer `CYDER_PREFIX` as the config key (`CYDER_SHARED_PREFIX` remains an alias).
- CrossOver bottles seed `cxbottle.conf` from the engine template; MapleStory OEM also injects `RAW_AUDIO_PARSE` and `zh_TW.UTF-8` locale.
- Rebuilds delete the old bottle first; incomplete OEM bottles (missing `cxbottle.conf`) are not treated as ready.

### Winetricks / cabextract

- Bundles a universal `cabextract` for the in-app Winetricks install path.

### MapleStory OEM flavor

- `scripts/create-cyder-maplestory-oem-app.sh` wraps the shared packager, swaps OEM launch/bootstrap helpers, and resigns.
- CrossOver Perl frontend flags are applied only for that frontend; official Mach-O wine does not receive them.

### Branding

- Packaging prefers `logo/AppIcons.zip` / `AppIcon.appiconset` when building `AppIcon.icns`.

## Install / upgrade

1. Download and unzip `Cyder-0.7.0.zip` (official) or `Cyder-maplestory-oem25-0.7.0.zip` (OEM).
2. Replace the previous `.app`; official and OEM can coexist because engine/bottle names differ.
3. If an OEM bottle previously failed for a missing `cxbottle.conf`, rebuild the bottle from settings.

## Known limitations

- MapleStory OEM compatibility work stays in the OEM flavor; it is not part of the general-purpose 0.7.0 engine.
- Apple Silicon still needs Rosetta 2; Swift settings / library UI still require macOS 12+.
